# 水果瑪莉・經典復刻

重現台灣民國七十年代風格的木紋「水果瑪莉（FRUIT MARY，俗稱小瑪莉）」機台。只做這一台，一種玩法：投幣、押水果、按 START、看燈跑。

**[直接遊玩 →](https://jia-hong-peng.github.io/xiaomali/)**　（iPhone Safari 直立優先，桌機也可）

> 純屬娛樂。所有金額都是虛擬的 NT$，沒有儲值、沒有金流、不能兌換任何東西。

## 怎麼玩

1. 點右上角的金屬**投幣器**，投入一枚 NT$10（= 10 分）。每天（台灣時間 00:00）口袋現金會補到 NT$100。
2. 按下排的橘色圓鍵押分，每按一下押 1 分，**按住會連發**，每門最多 50 分。押得越多，賠率越高的圖案越難停到。
3. 按 **START**，24 顆燈開始跑，慢慢減速停下。燈停在你押的圖案就中獎，得分＝押分×倍數。
4. 停在左右兩側正中央的「再一次」會再隨機送 1–3 個燈，押中任何一個都算。
5. 中獎後：按 **START** 把得分併入投幣分數繼續玩；或用 **WIN↔CREDIT** 兩顆鍵在得分與投幣分數間轉分；或按紅色的**猜小**（1–6）／**猜大**（8–13），猜對得分加倍、猜錯歸零。
6. 按 **PAY** 領回所有分數，硬幣會掉進下方金屬盤；點一下盤子取走硬幣。

沒人投幣一陣子後，燈會自己跑（待機燈光秀）；載入時有開機自我檢測。左下角的小開關可以開關音效。第一次點擊畫面後才會有聲音（瀏覽器限制）。

### 鍵盤（桌機）

| 鍵 | 動作 |
|---|---|
| `C` | 投幣 |
| `1`–`8` | 由左到右押 BAR、77、雙星、西瓜、鈴鐺、木瓜、橘子、蘋果 |
| `Q` / `W` | 得分→投幣分數 / 投幣分數→得分 |
| `Space` / `Enter` | START（得分狀態下為轉入得分） |
| `←` / `→` | 猜小 / 猜大 |
| `X` / `Backspace` | PAY（退幣） |
| `M` | 音效開關 |

## 規則依據

規則骨架取自經濟部電子遊戲機評鑑文件《水果瑪莉 FRUIT MARY》（圖案、倍數、押分 1–50、再一次、猜大小）。
這份文件是較晚期的機種，**不是 1980 年代的原廠資料**。24 格的排列、停燈機率與外觀都是推定或模擬，已逐項標示：

- [`docs/HISTORICAL_NOTES.md`](docs/HISTORICAL_NOTES.md) — VERIFIED / INFERRED / SIMULATED 與未解決的問題
- [`docs/RULES_AND_RTP.md`](docs/RULES_AND_RTP.md) — 燈位權重表、每一門 90% 的理論回收率、每日補發政策
- [`docs/TEST_REPORT.md`](docs/TEST_REPORT.md) — 測試結果

## 開發

純靜態網站，沒有建置步驟、沒有執行期相依套件。

```bash
npm test          # 單元測試（Node 內建 test runner，約 3 秒）
npm run serve     # 本機伺服器 http://127.0.0.1:8137/
```

瀏覽器端對端測試：啟動伺服器後開啟 `http://127.0.0.1:8137/tests/e2e.html`（在 iframe 內以真實 DOM 事件操作遊戲，標題會顯示 PASS/FAIL）。

| 檔案 | 職責 |
|---|---|
| `js/config.js` | 設定與歷史假設（圖案、倍數、燈位、權重、跑燈節奏） |
| `js/engine.js` | 規則與結算：純邏輯、可注入亂數、無 DOM |
| `js/storage.js` | 存檔與驗證，損毀資料安全還原 |
| `js/anim.js` | 跑燈排程與控制器（結果先定，動畫只負責走到） |
| `js/audio.js` | Web Audio 即時合成音效 |
| `js/art.js` / `js/cabinet.js` | 原創 SVG 圖案、木紋與紙張紋理、機台外觀 |
| `js/ui.js` | 把以上串起來：事件、顯示器、動畫 |
| `tools/solve-weights.mjs` | 重新求解停燈權重 |

亂數使用 `crypto.getRandomValues()`（拒絕取樣，無取模偏差）；不支援時才退回 `Math.random()`。
