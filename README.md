# 復古小瑪莉

仿台灣復古街機的 HTML 小遊戲，包含 24 格跑燈、八門圖案押注、投幣、退幣與音效。

**[直接遊玩](https://jia-hong-peng.github.io/xiaomali/)**

手機或電腦瀏覽器開啟後，先按「投幣 $10」、選擇圖案押注，再按「START 開始」。每日提供虛擬零用金 $5,000，台灣時間 00:00 重置。進度儲存在目前瀏覽器。

純娛樂模擬，無儲值、無真實金錢交易。

網站為單一 `index.html`，CSS 與 JavaScript 內嵌，無外部資產或建置依賴。由 GitHub Pages 從 `main` 分支根目錄發布。
